## Описание

Я короче накидал два файлика:


### scene_generator.py

Генерирует файл сцены для копелии в в своей директории. В сцене генерирует препятствия трех типов: 
- Здания
- Стены
- Столбы
- Также генерирует маркеры точек интереса (POI)

Имя файла(без расширения), размер сцены, количество препятствий и POI задается флагами, чтобы посмотреть флаги введите:  
`py scene_generator.py --help`


### main.py

Файл инициализирующий дроны и начинающий их полет

### sensor_test.py

Файл где должна быть демка взаимодействия с сенсорами (пока только высотомер)

### modules/quadcopter.py

Класс квадрокоптера

### modules/utils.py 

Файл с вспомогательными функциями. Сейчас там обертки для асинхронного вызова функций api


## Обновления

30.10 - Класс для квадрокоптера доведен до минимально рабочего состояния, теперь в нем асинхронные методы для управления несколькими дронами сразу. Пока дрон просто выбирает ближайшую цель из общего пула и удаляет её, для демо сойдет, но по сути тесты и подбор оптимального алгоритма распределения целей это главная задача работы.


01.11 - Квадрокоптеры теперь симулируют меш сеть и выбирают себе ближайшую цель через аукцион


07.11 - Фикс проблемы с синхронными вызовами ZMQ теперь все работает параллельно. Класс `Quadcopter()` теперь вынесен в `quadcopter.py`.


12.11 - Переделана структура проекта: 
modules - классы для копелли (пока только `Quadcopter()`) и вспомогательные функции
models - ttm файлы моделей копелии (QuadcopterSensors - квадрокоптер с камерой, высотомером, акселерометром, и гироскопом)
scenes - сцены для тестов

В класс квадрокоптера добавлен метод для поворота вокруг оси Z, а так же получение хэндлов датчиков и метод определения высоты через proximitysensor


## Проблемы/вопросы

- [ ] Пока непонятно какого вида нужны БПЛА самолетного (fixed wing) или коптеры. Было бы козырно добавить и те и те, но для БПЛА самолетного типа в коперии нет модели надо найти.
- [ ] При больших скоростях поворота дрон проскаивает свой угол и из-за этого может полпути пролетать поком пытаясь стабилизироваться. Надо либо придумать как поворачивать его плавно чтобы он не проскакивал, либо сделать так чтобы он сначала поворачивал и стабилизировался и только потом начинал движение.
