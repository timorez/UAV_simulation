## Описание

Я короче накидал два файлика:


### scene_generator.py

Генерирует файл сцены для копелии в в своей директории. В сцене генерирует препятствия трех типов: 
- Здания
- Стены
- Столбы\
- Также генерирует маркеры точек интереса (POI)

Имя файла(без расширения), размер сцены, количество препятствий и POI задается флагами, чтобы посмотреть флаги введите:  
`py scene_generator.py --help`


### main.py

Файлик на поиграть\
Тут наверное должны быть абстракции в виде классов над разными объектами из копелии по примеру  `class Quadrocopter()` и потом это наверное надо будет спрятать в отдельный модуль чтобы в процессе исследований уже не возвращаться к разборкам непосредственно с API копелии. 

Пока есть только класс для квадрокоптера с функцией постепенного увеличения высоты через перемешение таргета (если переместить таргет мнгновенно коптер просто уработается в землю)
